Inference Output Explorer

Load one `evaluation/inference.py` output directory, inspect run-level artifacts, switch across instance-level files, and drill into component summaries, component detail traces, and the final trajectory without leaving the browser.

Uses the browser's folder picker and reads files locally. The directory selector works best in Chromium-based browsers because it relies on `webkitdirectory`.
