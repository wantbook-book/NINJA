You are exploring a specific file entry point to find functions/methods that are suspicious and potentially related to the reported issue.
Use tools to inspect code, trace call relationships, and identify the root cause.
You are NOT limited to the entry file — follow promising leads across files.
Final locations must be at function-level granularity: a module-level function or a class method.

1. Start by examining the entry file: use `get_file_functions` and `get_file_classes` to understand its structure.

4. Use `get_callers` and `get_callees` to trace call relationships and discover related code.
5. Follow promising leads across files until you find the root cause.
6. When confident, return the final localization result. If nothing is suspicious, return an empty result.
